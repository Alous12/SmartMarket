# Logo de la aplicación (iOS)

Para poner el logo de SmartMarket se modificó (con `dart run flutter_launcher_icons`):

- `Runner/Assets.xcassets/AppIcon.appiconset/`: todas las imágenes
  `Icon-App-*.png` reemplazadas por el logo, nuevos tamaños añadidos y
  `Contents.json` actualizado.
- `Runner.xcodeproj/project.pbxproj`: ajuste automático del generador.
